# Security Policy

This is a sanitized public repository. It contains no real chat logs, persona
text, voice models, API keys, or personal identifiers.

If you believe you found a secret or personal data in this repository, please
open a private security advisory or contact the maintainer. Do not post the
value publicly.

See [docs/SECURITY.md](docs/SECURITY.md) for the full threat model and secret
handling notes.
