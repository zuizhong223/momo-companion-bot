## 回复兜底

新增四个小型、可测试的确定性兜底模块：

| 模块 | 触发 | 作用 |
|---|---|---|
| `game_hint.py` | 游戏/具体内容 | 先接具体信息，不默认“在吃饭/挂着”，不推荐买号 |
| `daily_hint.py` | 睡眠时间问句 / “水到渠成”类总结 | 两条气泡或四条短回复轮换，不追问 |
| `comfort_hint.py` | 第一人称累/疼 | 先接住，不追问“怎么了/吃药了没”；玩笑/否定句不触发 |

这些兜底在 `result_decorate` 里按优先级执行，避免模型每次重生成时把已经定稿的回复改坏。
